O que é Segurança da Informação?

Segurança da Informação é o conjunto de práticas utilizadas para proteger dados contra acessos não autorizados, alterações, perdas e vazamentos. Ela é importante para proteger informações pessoais e empresariais.

Confidencialidade

Somente pessoas autorizadas podem acessar as informações.

Integridade

Garante que os dados não sejam alterados de maneira indevida.

Disponibilidade

Garante que as informações estejam disponíveis quando necessárias.

Matérias estudadas no curso

Desenvolvimento para Web

Aprendemos a criar sites utilizando HTML e CSS, organizando conteúdos e desenvolvendo páginas.

Redes

Aprendemos como os computadores se conectam e compartilham informações pela internet.

Linguagem Técnica de Programação

Estudamos conceitos de programação, lógica e termos utilizados na área de tecnologia.

Modelagem de Sistemas

Aprendemos a planejar sistemas, organizar processos e identificar necessidades dos usuários.

Banco de Dados

Aprendemos a armazenar, organizar e consultar informações de maneira estruturada.

Projeto Integrado

Web Design + Banco de Dados

O Projeto Integrado reuniu os conhecimentos adquiridos durante o curso. Desenvolvemos a parte visual de um site e estudamos como organizar suas informações em um banco de dados.

Conclusão: Como foi o curso?

Durante o curso técnico, aprendemos diferentes conhecimentos na área de tecnologia. Estudamos desenvolvimento de sites, redes, programação, modelagem de sistemas e banco de dados. O curso foi importante para desenvolver nosso raciocínio lógico, criatividade e capacidade de resolver problemas. Também entendemos a importância da Segurança da Informação e de proteger os dados no ambiente digital.
